# DIRETTORE — routine A4

Spazio Santini · FDM · Appendi alla postazione

## MATTINO (≤10 min)
1. Accedi → **Dashboard - Overview** → leggi KPI **Offerte / AVOR / Produzione / Fatture**.
2. Scorri **Ultime notifiche** → se ritardi, apri codice e assegna a UT / Capo produzione.
3. **Dashboard - Vendita** → **Alert Offerte**: tratta scadenze oggi/domani (Kanban **Offerte**).
4. **Dashboard – Fatturazione** → se **Scadute** > 0, avvisa Amministrazione.
5. **Dashboard - Produzione** → riepilogo 3 settimane **P / I / S**: allinea Posa/Service se sbilanciato.

## GIORNATA
6. Offerta chiusa: Kanban **Offerte** → **Vinta** o **Persa** → conferma dialog (motivazione se Persa).
7. Cliente chiama: card → **Follow-up Offerta** → **Salva** / **Salva e Sposta** in **Trattativa**.
8. Escalation da fabbrica/posa: apri card citata; decidi priorità o scala owner; non lasciare colonna ambigua.
9. A metà giornata: ripeti **Alert Offerte** (zero alert `high` scoperti).

## SERA (≤10 min)
10. Nessuna offerta in scadenza oggi senza follow-up o **Vinta**/**Persa**.
11. **Scadute** fatture note ad Amministrazione.
12. Non usare menu **Notifiche** (stub). Dettaglio: `docs/routine-operative-santini.md`.
