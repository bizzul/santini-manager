# AMMINISTRAZIONE — routine A4

Spazio Santini · FDM · Appendi alla postazione

## MATTINO (≤10 min)
1. **Dashboard – Fatturazione** → **Stato Fatture**: **Da Emettere / Emesse / Scadute / Pagate**.
2. Se **Da Emettere** > 0 → Kanban **Fatture OUT** colonna **To Do**: prepara emissione.
3. Se **Scadute** > 0 → card in **Inviata**: sollecita; priorità anche da **Aging** `90+`.
4. **Presenze** → **Richieste in attesa**: evadi o assegna.
5. (Admin) solo su segnalazione: **Collaboratori** / permessi moduli-kanban.

## GIORNATA
6. Arrivo da **Conferma Fatturazione**: lavora **To Do** → sposta in **Inviata** (data scadenza valorizzata).
7. Pagamento ok → sposta **Inviata** → **Pagata** (mai prima).
8. Nuovo cliente: **Clienti** o **+** → **Cliente** prima di chiudere pratiche.
9. Ore mancanti: **Ore** → **Aggiungi report ore** / **Nuovo report ore**.

## SERA (≤10 min)
10. Nessuna fattura «pronta» ferma in **To Do** senza nota.
11. Elenco **Scadute** aggiornato (sollecito fatto o pianificato).
12. Ore di competenza inserite. Dettaglio: `docs/routine-operative-santini.md`.
