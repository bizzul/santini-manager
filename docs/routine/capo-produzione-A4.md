# CAPO PRODUZIONE — routine A4

Spazio Santini · FDM · Appendi alla postazione

## MATTINO (≤10 min)
1. **Dashboard - Produzione** → **Stato Produzione** (carico per board/reparto).
2. Riepilogo 3 settimane: colonna **Questa settimana** breakdown **P / I / S**.
3. **Calendario Produzione**: svuota **Da definire** di oggi; risolvi **conflitti** / orari.
4. Apri board **Kanban Produzione**: arrivi in To Do da AVOR; priorità badge `Oggi`/`-Ng`.
5. Allinea Posa se **I** scoperto rispetto ai pezzi pronti.

## GIORNATA
6. Avanza lavorazioni con DnD colonna → colonna (stato = colonna).
7. Materiale mancante: stop colonna → verifica **Magazzino** → aggiorna date → avvisa UT.
8. Pronto: colonna `invoicing` (es. **Spedito**) → **Conferma Fatturazione**.
9. Se usati: **Imballaggio** / **Quality Control** prima della fatturazione.

## SERA (≤10 min)
10. Calendario: **Da definire** = 0 per oggi.
11. Pezzi pronti passati in fattura o Amministrazione avvisata.
12. **Ore** + eventuali **Errori**. Dettaglio: `docs/routine-operative-santini.md`.
